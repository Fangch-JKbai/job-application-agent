# Roadmap

当前版本已实现通知到申请/待办的默认自动流程、QQ/163/126接入、持久任务与故障接管、本地四服务发布和备份恢复。

下一轮优先积累真实脱敏案例，并用固定划分验证提取和匹配质量；将失败按字段、匹配、日期和业务动作分类，保留首次结果。附件解析和更广的邮箱文件夹覆盖应由具体需求驱动。

工程方面继续定位突发提交的连接等待长尾，保留预先定义的200ms目标；增加托管CI、按实际需要安排备份调度和异地存储，再考虑较长时间的运行验证。仓库当前没有GitHub Actions工作流，开源不等于CI已验证。

远程部署需另行准备可控服务器、TLS、域名、监控与恢复演练；多用户注册和邮箱所有权隔离属于独立扩展。当前不宣称公网服务、生产并发容量或生产恢复目标已达成。
