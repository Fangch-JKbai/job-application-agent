# P9冻结评测材料

p9-v1包括8条开发案例和10条合成留出案例，均由同一AI助手编写，不是用户求职经历或外部盲测。真实脱敏材料当前0条，单独保留real-redacted入口，不从开发库或邮箱采集私人通知。

两个文件的具体文本、初始数据、脚本补充、核对说明与期望在开发模型实测前一起冻结，SHA-256写入dataset-lock.json。开发案例可用于修订；留出案例仅在最终代码冻结后进行一次真实模型运行，看到输出后不调参并重报“未见准确率”。案例主题与已知业务规则有重叠，不能当作随机代表样本。

source_cases只表示业务主题来源，正文大多重新构造。元数据勘误：D02.source_cases里的P1-021误标，实际相关来源为P1-002与P8-live；P1-021是Offer案例。该字段不参与模型输入或评分，保留冻结原文件及此处更正，不重写数据哈希。

初始业务数据只播种本案例指定申请和事项。模型只读取正式接口提供的通知、当前状态和工具结果，不读取expected、文件路径或case ID。评测脚本按预定问题字段发送已写好的回答，明确确认由脚本模拟；不会根据模型输出临时编造答案。D08的核对是脚本模拟的用户动作，不是真实用户纠正行为。

评分器采用预先声明的字段、时间精度、目标及数据库断言，允许one_of定义的合理表示。自由表述的标题和追问措辞不逐字评分；提取层不单独评分time_note，最终数据库对照仍包括time_note与notes；运行时证据校验通过不等于外部人工质量审核。原始结果保留供复查。

pricing.json为2026-10-28核对的官方价格快照，记录deepseek-flash峰/谷价范围及缓存计价。只计算取得用量的估算范围，不推断账户实际扣费。没有用量、缓存计数不一致或模型不匹配时保留未知。
